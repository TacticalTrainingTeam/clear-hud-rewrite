# Clear Hud Rewrite

**Clear Hud Rewrite** hides your chat when on multiplayer servers. Toggle it with a configurable key-press.

Rewrite of the original Clear Hud by Soldia.

# Requirements

- [CBA_A3](https://github.com/CBATeam/CBA_A3)
